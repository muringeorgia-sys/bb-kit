# Инструкция для ИИ-агента

Пользователь дал ссылку на этот репозиторий и просит установить сборку («установи», «поставь bb-kit», «настрой под меня»).

1. Прочитай навык установки: `plugins/bb-kit-setup/skills/bb-kit-setup/SKILL.md`
   (по ссылке: https://raw.githubusercontent.com/muringeorgia-sys/bb-kit/main/plugins/bb-kit-setup/skills/bb-kit-setup/SKILL.md).
2. Выполни его по шагам: проверка компьютера → план одной формой → установка после «да» → анкета (паспорт, продукт, команда, Jira, Telegram) → таблица «что подстроить» → подстройка только после второго «да» → итог.
3. Не проси секреты в чат и не перезаписывай существующие файлы правил.

Если навык `bb-kit-setup` уже установлен (Claude Code: `bb-kit-setup@bb-kit`), можно вызвать его: `/bb-kit-setup`.

Что в сборке — `README.md`. Правила для работы над самим репозиторием: перед коммитом `tools/check-public.ps1` (0 находок), без рабочих и личных данных.
