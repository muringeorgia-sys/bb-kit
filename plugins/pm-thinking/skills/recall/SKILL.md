# Где я остановился

Тему назвал пользователь. Нет темы — спроси одним вопросом. «Недавно» = последние 7 дней, если не сказано иначе. Назови рамку в первой строке ответа: тема и период.

## Источники — по порядку, только чтение

| # | Где | Как |
|---|---|---|
| 1 | Документы проекта | поиск по базе документов из правил проекта (CLAUDE.md, раздел о вики или базе) по теме и синонимам |
| 2 | Логи задач | папка логов из правил проекта (например, `logs/`) — поиск по теме, свежие сначала |
| 3 | Память | `MEMORY.md` и файлы памяти по теме |
| 4 | Журнал решений | файл решений из правил проекта, если есть — строки по теме |
| 5 | Треды bb | `bb thread search "<тема>"`, затем `bb thread output <id>` только у 1–3 самых свежих |
| 6 | Трекер задач | эпики и задачи по теме: статус, релиз, последний комментарий |

- Читай только найденные места, не файлы целиком. Больше 10 файлов или тредов — отдай чтение субагенту `general-purpose` (model sonnet), в основной тред — только выжимку.
- Источник недоступен — так и напиши, не пропускай молча.
- Не меняй ничего в источниках.

## Ответ — один экран

1. **Капсула** — до 5 пунктов: что это за работа и где она сейчас.
2. **Нити** — по строке, у каждой один статус: `[в проде]`, `[в трекере: статус, релиз]`, `[PRD готов]`, `[в документации]`, `[в работе]`, `[заморожено]`, `[не начато]`.
3. **Решения** — принятые, с датой.
4. **Проблемы** — до 5: что не сработало, что откатили, что повторяется.
5. **Следующий шаг** — один, конкретный.

Каждое утверждение — со ссылкой на источник: путь файла, ключ задачи, id треда. Не выдумывай: нет данных — «не найдено».
