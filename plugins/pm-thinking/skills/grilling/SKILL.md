# Разбор идеи вопросами

Задавай вопросы, пока не будет общего понимания. Держи в голове **дерево решений**: каждое решение тянет за собой зависимые.

## Раунды

1. **Граница** — решения, для которых все предыдущие уже приняты. Их можно спросить сейчас, не угадывая ответы.
2. Один раунд — одна форма `AskUserQuestion`, до 4 вопросов из границы. Остальные — следующим раундом.
3. В каждом вопросе первый вариант — твоя рекомендация с пометкой «(Рекомендую)». В описании варианта — что он даёт и чего стоит.
4. Формулируй так, чтобы «да» принимало рекомендацию.
5. Вопрос, ответ на который зависит от другого открытого вопроса этого раунда, — в следующий раунд.
6. После ответов пересчитай границу и задай следующий раунд.

## Факты ищешь ты, решения принимает пользователь

- Факт из файлов, баз данных, трекера задач и документации находишь сам. Большой поиск — в субагенте. Пользователя о фактах не спрашивай.
- Пока субагент ищет, задавай вопросы, которые от этого факта не зависят.
- Если в проекте есть база знаний о продукте (сегменты, ценность, прошлые решения), сверяй вопросы с ней.

## Конец

Разбор закончен, когда граница пуста: все ветки пройдены, ничего не принято молча. До подтверждения пользователя ничего не делай по итогам.
