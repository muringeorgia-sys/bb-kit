# bb-kit-setup — установка по ссылке

Цель: человек дал ссылку на bb-kit и сказал «установи». Ты ставишь сборку, узнаёшь, кто он и как работает, и подстраиваешь установленное только после его «да».

Репозиторий: `https://github.com/muringeorgia-sys/bb-kit`. Описание плагинов — `README.md` в корне, настройки каждого bb-плагина — `bb/plugins/<id>/README.md`.

## Правила

- Пиши по-русски, коротко, списками и таблицами. Вопросы — формой (инструмент вопросов: `AskUserQuestion` или аналог), рекомендуемый вариант первым. Нет инструмента — задай вопросы одним сообщением списком.
- Без согласия ничего не ставь и не меняй. Согласие на установку не равно согласию на подстройку: это два разных «да».
- Секреты (API-токены Jira, токен Telegram-бота, api_id и api_hash Telegram) **не проси писать в чат**. Человек вводит их сам: bb → Settings → Installed plugins → плагин, или командой в своём терминале.
- Не перезаписывай существующие файлы правил (`~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.bb/AGENTS.md`). Если файл есть — покажи, что добавишь, и допиши в конец после «да», или пропусти.
- Плагин уже стоит (то же id из другого источника) — не переустанавливай, скажи об этом. Установка из каталога переключит источник его плагина.
- Не выдумывай данные о человеке и его продукте. Нет ответа — оставь подсказку в шаблоне.

## Шаг 1. Что есть на компьютере

Проверь молча, без вопросов:

| Что | Команда |
|---|---|
| ОС | `uname -s` или `$env:OS` |
| Claude Code | `claude --version` |
| bb | `bb --version`, `bb plugin list` |
| Codex | `codex --version` |
| git | `git --version` |
| Python, uv (нужны «Ответам TG» и «Выручке фич») | `python --version` или `py -3 --version`, `uv --version` |
| Уже установлено | `claude plugin marketplace list`, `claude plugin list`, `bb marketplace list` |

## Шаг 2. План установки — одна форма

Покажи, что нашёл, и спроси одной формой:

1. **Что поставить** (мультивыбор, по умолчанию отмечено всё, что подходит к найденным программам):
   - навыки Claude Code: pm-thinking, pm-research, pm-delivery, prd-pipeline, сторонние humanizer, superpowers, andrej-karpathy-skills, caveman;
   - панели bb: О себе, Агенты, Open In App (только Windows), GenUI, Ответы TG, Релизы, Конвейер PRD, Выручка фич;
   - навыки для Codex (ссылки на папку клона);
   - шаблоны правил: `rules/CLAUDE.md`, `rules/bb-AGENTS.md`.
2. **Куда клонировать** репозиторий (нужно для Codex и правил): по умолчанию `~/bb-kit`.

Добавь оценку: ~5–10 минут, без субагентов. Для «Ответов TG» и «Выручки фич» предупреди о зависимостях (Python, uv, openpyxl, telegram-mcp) — их ставит человек сам по README плагина, или ты после отдельного «да».

## Шаг 3. Установка

Только выбранное. Команды — из раздела «Установка» в `README.md` репозитория, кратко:

```bash
git clone https://github.com/muringeorgia-sys/bb-kit.git ~/bb-kit        # если выбраны Codex или правила
claude plugin marketplace add muringeorgia-sys/bb-kit
claude plugin install <плагин>@bb-kit                                     # по одному на каждый выбранный
bb marketplace add git:github.com/muringeorgia-sys/bb-kit@main --subdirectory bb
bb plugin install <id>@bb-kit --yes                                       # по одному
```

- Codex: ссылки на `~/bb-kit/plugins/*/skills/*` в `~/.codex/skills` (команды в README).
- Правила: скопировать шаблон, если файла нет; есть — см. «Правила» выше.
- После каждого шага проверь: `claude plugin list`, `bb plugin list` — статус `running`. Ошибка — покажи текст и предложи вариант, не повторяй вслепую.

## Шаг 4. Паспорт и работа — одна форма

Спроси (все поля необязательные, «пропустить» — нормальный ответ):

| Блок | Вопросы |
|---|---|
| Кто вы | Имя, роль, компания или сфера; в чём сильны, чего не любите делать |
| Продукт | Что за продукт, для кого, как зарабатывает; направления выручки; валюта |
| Цели и приоритеты | 1–3 цели на год; что важнее всего |
| Команда | Кто есть: дизайн, разработка, QA, аналитика; кто согласует решения |
| Как работаете | Дни и часы, устройство, ограничения по доступам |
| Как отвечать | Длина, формат (списки, таблицы, файлы), обращение на «ты» или «вы» |
| Чего избегать | Темы и вопросы, которые не нужны |
| Трекер | Есть ли Jira Cloud; адрес (`https://<компания>.atlassian.net`); ключи проектов: эпики, разработка, дизайн, QA; продукты в трекере |
| Telegram | Отвечать на упоминания из bb («Ответы TG»)? Нужен ли бот релизов, в какой чат |
| Вики и PRD | Где публикуете PRD; папка проекта с PRD |

## Шаг 5. Что подстроить — показать и спросить «да»

Собери таблицу «что изменится» по ответам — только то, на что есть данные:

| Где | Что | Как |
|---|---|---|
| О себе | Паспорт из блоков «Кто вы»…«Чего избегать» в формате шаблона плагина (заголовки `## Кто я`, `## Мои цели`, `## Как я работаю`, `## Мои ограничения`, `## Мои приоритеты`, `## Как мне отвечать`, `## Чего избегать`). Подсказки `<…>` без ответа убрать | `bb plugin config about-me set about "<текст>"`. Многострочный текст: записать во временный файл и передать `"$(cat файл)"`; не вышло — дать текст человеку для вставки в Settings |
| Ответы TG | `about` (одна строка «кто вы»), `deviceName` | `bb plugin config tg-mentions set <ключ> <значение>`; api_id и api_hash — человек сам |
| Релизы | `jiraUrl`, `jiraEmail`, `projectEpic`, `projectDev`, `projectDesign`, `projectQa`, `products` (JSON `[{"id":"a","name":"Продукт A","emoji":"🚀"}]`, id — латиница), `utcOffset`, `tgChatId` | `bb plugin config releases set …`; `jiraToken`, `tgToken` — человек сам |
| Выручка фич | `productName`, `currency`, `revenueLines` (через запятую), `trackerUrl`, `trackerEmail` | `bb plugin config feature-revenue set …`; `trackerToken` — человек сам |
| Конвейер PRD | `references/product-context.md` навыка prd: продукт, пользователи, данные, папки, вики и трекер | В кэше плагина правки пропадут при обновлении. Предложи копию для правки: `bb plugin rpc call prd-pipeline copy_to_user --input-file <файл с {}>` (или скопировать `~/bb-kit/plugins/prd-pipeline/skills/prd` и `agents/` в `~/.claude/skills/prd` и `~/.claude/agents`, затем `claude plugin uninstall prd-pipeline@bb-kit`), и заполни копию |
| Правила | `~/.claude/CLAUDE.md`, `~/.bb/AGENTS.md`: обращение, формат ответов, рабочие часы | Дописать блок в конец, не трогая чужое |

Спроси одной формой: «Подстроить?» — варианты «Да, всё», «Выбрать пункты», «Нет». Только после «да» — применяй. Затем `bb plugin config <id>` для проверки и `bb plugin reload <id>`.

## Шаг 6. Итог

Короткая таблица: что установлено, что подстроено, что осталось сделать человеку:

- секреты по каждому плагину (где ввести);
- зависимости: telegram-mcp и вход по QR для «Ответов TG» (`bb/plugins/tg-mentions/README.md`), Python + openpyxl для «Выручки фич»;
- обновление: `claude plugin marketplace update bb-kit`, `bb marketplace refresh bb-kit`, `bb plugin update --all`, `git -C ~/bb-kit pull`.

Ничего не публикуй и никуда не отправляй данные человека.
