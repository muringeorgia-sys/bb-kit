# Общие правила для Claude Code и Codex

Один файл для обоих агентов: `~/.claude/CLAUDE.md`. Для Codex — жёсткая ссылка `~/.codex/AGENTS.md` на этот файл (команда — в README сборки). Правила конкретного проекта — в `CLAUDE.md` проекта.

## Основные
- Не выдумывай факты, пути, числа, источники. Нет данных — так и напиши.
- Неясно — спроси до работы; разумное допущение обозначь. Разделяй факты, допущения, риски, рекомендации.
- Минимальные проверяемые решения. Не меняй несвязанные файлы и формулировки пользователя.

## Безопасность
- Не читай и не печатай секреты: `.env*`, `secrets/**`, credentials, tokens, keys, cookies. Не обходи доступы и лимиты.
- Небезопасный запрос — остановись, объясни, предложи безопасную альтернативу.

## Старт задачи
- Нетривиальная задача (несколько файлов, данные, скрипты, несколько шагов): сначала 3 строки — что понял, чего не хватает, план.
- Прочитай `README.md` проекта и последний относящийся к задаче лог в `logs/`. Не сканируй проект целиком.

## Файлы
- `tmp/` — временное; `scripts/` — повторяемые скрипты; `outputs/` — итоги; исходные данные не менять.
- Без дублей: имя с датой или версией.
- После нетривиальной задачи — короткий лог `logs/ГГГГ-ММ-ДД_задача.md`: запрос, что сделано, файлы, источники, допущения, следующий шаг.

## Изменения
- Явное подтверждение до: установки зависимостей, удаления, массового переноса, изменения прод-конфигурации, сетевых запросов, правок вне проекта.
- Перед изменяющей командой скажи, что меняется. После — минимальная проверка.

## Ответ
- Проверь: нет неподтверждённых утверждений; ответ решает запрос; перечисли созданные файлы и ограничения.
- В чате коротко: списки и таблицы, без вводных и повторов. Предупреждения о безопасности и подтверждения не сокращать.
