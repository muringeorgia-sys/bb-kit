# Выручка фич — плагин bb

Оценивает выручку фич вашего продукта по одной методике: ожидаемый эффект в месяц, вилка, уверенность, трудоёмкость и ICE для приоритизации. Показывает, из чего складывается каждое число, и пересчитывает «что если» на том же калькуляторе. После первого запуска в панели — 4 демо-фичи условного онлайн-сервиса курсов (все числа выдуманы).

## Что делает

| Вкладка | Что видно |
|---|---|
| Релиз | Ожидаемая выручка релиза, вилка, итог к плану, полоса «из чего складывается» по строкам выручки, список фич с проблемами и ICE |
| Карточка фичи | «Путь числа»: входы, шаги расчёта, торнадо по входам, деньги по сценариям, замер, проверки фичи |
| Рычаги | Ползунки сильных входов: было → стало, порог, при котором фича уходит в ноль |
| Приоритеты (В трекере) | Карта «выручка × трудоёмкость», порядок по ICE; с трекером — запись Impact, Confidence, Effort, ICE в эпик |
| Замеры | Календарь замеров, прямые метрики с прогнозом, «+ факт», точность прошлых прогнозов |
| ИИ | «Оценить новые», «Переоценить все», «Ревью» — треды bb, которые правят `features.json` |
| ? | Шпаргалка методики |

## Методика кратко

- Сценарии негатив / ожидаемый / позитив — «1 из 10». Компонент фичи = одна строка выручки + вид денег + механика; у каждого компонента — шаги расчёта по одной операции.
- Уровни входов У1–У5 (факт → гипотеза). **Уверенность фичи — по уровню главного входа** (того, что сильнее всего двигает итог): У1 100 %, У2 80 %, У3 50 %, У4 30 %, У5 20 %.
- **Вилка — по независимым входам**: ожидаемый ∓ корень из суммы квадратов сдвигов.
- **План по строкам**: база и план каждой строки выручки по месяцам — блок «К плану по строкам».
- **Замеры**: у фичи прямая метрика с прогнозом и окнами 14/30/90 дней, факты дописываются из панели.
- Срок — отдельно от эффекта: сдвиг в релизах по статусу эпика. ICE = Impact × Confidence ÷ Effort (часы S 16, M 40, L 80, XL 160).
- Калькулятор сверяет конфиг с правилами (лист и блок «Проверки»): нет источника, вилка не по правилу, нет шагов, нет порога окупаемости и др.

Полный текст — `Методика.md` в папке данных (кнопка «Методика» в панели).

## Что нужно

| Что | Зачем |
|---|---|
| bb ≥ 0.46 | Сам плагин |
| Python ≥ 3.10 и пакет `openpyxl` (`pip install openpyxl`) | Калькулятор `build.py`: расчёт и xlsx |
| По желанию: облачный трекер Atlassian (REST API v3), email и API-токен | Статус и релиз эпиков, запись ICE в эпик |
| По желанию: агент в bb (Claude Code) | Кнопки ИИ: оценка и ревью фич |

## Установка

```bash
bb marketplace add git:github.com/muringeorgia-sys/bb-kit@main --subdirectory bb
bb plugin install feature-revenue@bb-kit
```

Python не найден или нет `openpyxl` — панель покажет ошибку с тем, что проверено. Укажите путь в настройке «Путь к Python».

## Настройки

bb → Settings → Installed plugins → «Выручка фич», или `bb plugin config feature-revenue set <ключ> "<значение>"`.

| Ключ | Что | По умолчанию |
|---|---|---|
| `productName` | Название продукта для подсказок ИИ | «ваш продукт» |
| `currency` | Валюта, если в конфиге нет поля `currency` (демо пишет её в конфиг при создании) | ₽ |
| `revenueLines` | Строки выручки через запятую: порядок цветов и список строк для ИИ | Подписки, Разовые покупки, Реклама |
| `dataDir` | Папка данных | `~/.config/bb-feature-revenue` |
| `pythonPath` | Путь к Python | `python`, `py -3` или `python3` из PATH |
| `trackerUrl` | Адрес трекера, `https://<ваш-сайт>.atlassian.net` | пусто — без трекера |
| `trackerEmail` | Email, к которому выпущен токен | пусто |
| `trackerToken` | API-токен (секрет bb, в панель не уходит) | — |
| `trackerJql` | Какие эпики читать | `issuetype = Epic AND updated >= -180d ORDER BY updated DESC` |
| `iceFields` | id числовых полей Impact, Confidence, Effort, ICE через запятую | пусто — ICE только в панели |
| `aiProjectId`, `aiEnvironmentId` | Проект и окружение bb для тредов ИИ | пусто — проект по умолчанию, папка данных |

Без трекера статус и плановый релиз берутся из полей фичи `status` и `planned`. С трекером плагин раз в день (будни 10:15 и после запуска bb) и по кнопке «Сверить сейчас» пишет `tracker.json` и пересчитывает ICE, если разработчики поменяли Effort. Effort в эпик пишется только в пустое поле.

## Данные

Папка `~/.config/bb-feature-revenue/`:

| Файл | Что |
|---|---|
| `releases/features.json` | Все фичи. Первый запуск — демо-фичи `DEMO-1…4`; замените своими. Поля — в `Методика.md` |
| `releases/ГГГГ-ММ-ДД.json` | По желанию: снимки оценки одного релиза |
| `tracker.json` | Эпики, статусы, релизы из трекера (пишет плагин) |
| `out/` | xlsx и md: `python py/build.py releases/features.json --release all` |
| `reviews/` | Ревью и запуски ИИ |
| `ice/` | Журнал записи ICE в трекер |
| `py/` | Скрипты калькулятора, плагин обновляет их сам при запуске |
| `Методика.md` | Методика и поля конфига, плагин обновляет сам |

## Файлы плагина

| Файл | Что |
|---|---|
| `server.ts` | Настройки, RPC панели, сверка с трекером |
| `calc.ts`, `ice.ts`, `releases.ts`, `ai.ts` | Процесс калькулятора, ICE, список релизов, треды ИИ |
| `app.tsx`, `review.tsx` | Панель и режим ревью |
| `core/build.py`, `measure_fact.py`, `review_mark.py` | Калькулятор, запись факта замера, отметка ИИ в ревью |
| `core/py_scripts.mjs` | Те же скрипты строками (bb собирает плагин в один файл). После правки `.py`: `node core/gen_py.mjs` |
| `core/core.mjs`, `demo.mjs`, `method.mjs` | Папка данных, поиск Python, клиент трекера; демо-фичи; текст методики |
| `core/test_core.mjs` | Проверка без bb: `node core/test_core.mjs` → «ошибок 0» |

Тема панели рассчитана на тёмную тему bb; светлая не проверялась.
