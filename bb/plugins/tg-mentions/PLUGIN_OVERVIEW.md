# Ответы TG

Панель «Ответы TG» в сайдбаре bb. Логика — `core/core.mjs`, установка и настройка — `README.md`.

| Вкладка | Что видно |
|---|---|
| Ответить | Упоминания: «Нужен ответ», «Ты уже писал после», «Можно не отвечать». Карточка: контекст, 3 варианта, подсказка, поле ответа |
| Черновики в TG | Ответы, отправленные черновиком в Telegram; закрываются сами, когда ты отправишь ответ |
| Отвечено | Что отправлено, каким путём, похожесть на вариант |
| Скрыто | Скрытые карточки, «Вернуть» |
| Тон и обучение | Доля «без правок» по неделям, твои правила, профиль тона, что ты правишь |
| Настройки | Глубина поиска, имена без @, личка, автоварианты, модель, пересборка профиля, игнор чатов, вход в Telegram |

| Кнопка / расписание | Что делает |
|---|---|
| По расписанию (по умолчанию будни 10:00–17:45, каждые 15 мин) | Поиск упоминаний + варианты для новых |
| Отправить | Ответ в Telegram reply-сообщением, после подтверждения |
| Черновик в Telegram | Текст в поле ввода нужного чата с ответом на сообщение |
| Уже ответил | Закрыть; если после упоминания было твоё сообщение — оно идёт в обучение |
