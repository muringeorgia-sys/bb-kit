# Агенты

Панель «Агенты» в сайдбаре bb и виджет «Мои агенты» на главной.

| Действие | Что происходит с файлом |
|---|---|
| Включить / выключить | переносится между `~/.claude/agents` и `~/.claude/agents-disabled` |
| Сохранить | перезаписывается `~/.claude/agents/<имя>.md` |
| Новый | создаётся `~/.claude/agents/<имя>.md` |
| Удалить | переносится в `~/.claude/agents-trash` (можно вернуть) |
| Запустить | новый тред с промптом «Запусти субагента <имя>:» |
