# Конвейер PRD - плагин bb

Панель для навыка `/prd`: видно цепочку агентов Lite и Full, модели, параметры и тексты навыка; любую правку можно сохранить из панели, попросить словами (черновик ИИ) и откатить. Навык и агенты ставятся отдельно - плагином Claude Code `prd-pipeline` из этого же репозитория.

## Что делает

| Вкладка | Что видно и что меняется |
|---|---|
| Цепочка | Lite, Full, «грузи», «обнови» - таймлайн по волнам<br>перенос агентов, шаги, стоп-точки, текст задания<br>Lite и Full пересобирают блоки в `SKILL.md` |
| Агенты | Модель, уровень, лимит, вкл/выкл - в шапке файла агента |
| Параметры | Лимиты слов и критериев, концепция, режим по умолчанию, ревьюер<br>одно поле - все места в текстах |
| Тексты | Любой `.md` навыка (включая `product-context.md`), роли и агента; `settings.json` |
| Правки | «Поменять словами» → тред bb правит черновик → «Принять» / «Отклонить»<br>журнал, версии, «Вернуть как было» |
| Прогоны | `run_log.md` из папок `<Фича>_материалы` |

Каждое сохранение сначала показывает «было / стало». Эталонный прогон - кнопка в шапке (тред bb по `evals/README.md` навыка).

## Что нужно

| Что | Зачем |
|---|---|
| bb ≥ 0.46 | Сам плагин |
| Claude Code и плагин `prd-pipeline@bb-kit` | Навык `/prd` и агенты `prd-*`, которые правит панель |
| Плагин `humanizer@bb-kit` (желательно) | Финальная чистка PRD |
| Плагин Codex для Claude Code (по желанию) | Ревью PRD второй моделью; без него конвейер пишет «Codex: недоступен» |

## Установка

```bash
claude plugin marketplace add muringeorgia-sys/bb-kit
claude plugin install prd-pipeline@bb-kit
bb marketplace add git:github.com/muringeorgia-sys/bb-kit@main --subdirectory bb
bb plugin install prd-pipeline@bb-kit
```

Затем заполните `references/product-context.md` навыка (вкладка «Тексты» → `references/product-context.md`): продукт и прод, пользователи, источники данных, папка PRD, вики и трекер. Это единственный файл с данными вашего продукта.

## Настройки

bb → Settings → Installed plugins → «Конвейер PRD». Все поля можно оставить пустыми.

| Ключ | Что | По умолчанию |
|---|---|---|
| `skillDir` | Папка навыка prd | `~/.claude/skills/prd`, если он есть; иначе кэш плагина Claude: `~/.claude/plugins/cache/<каталог>/prd-pipeline/<версия>/skills/prd` (самая свежая) |
| `agentsDir` | Папка агентов `prd-*` | `agents/` плагина рядом с навыком или `~/.claude/agents` |
| `dataDir` | Журнал, версии, черновики | `~/.config/bb-prd-pipeline` |
| `runsRoot` | Корень проекта с папками PRD для вкладки «Прогоны» | пусто - вкладка пустая |
| `projectId` | Проект bb для тредов «Поменять словами» и эталона | личный проект bb |
| `environmentId` | Окружение этого проекта | окружение проекта по умолчанию |

## Правки в кэше плагина пропадут при обновлении

Если навык найден в кэше плагина Claude Code, панель правит его там. `claude plugin update` перезапишет кэш, и правки пропадут (журнал и версии в `dataDir` останутся). Чтобы править надолго, сделайте копию для правки:

1. Скопировать навык и агентов в `~/.claude` (не перезаписывает существующие - иначе отказ):

   ```bash
   echo {} > empty.json
   bb plugin rpc call prd-pipeline copy_to_user --input-file empty.json
   ```

2. Отключить Claude-плагин, чтобы не было двух навыков prd и двух наборов агентов: `claude plugin disable prd-pipeline@bb-kit`.
3. Перезагрузить плагин bb: `bb plugin reload prd-pipeline`. Панель найдёт копию в `~/.claude/skills/prd`.

В копии агенты вызываются без префикса (`prd-core-pm`), из плагина - с префиксом (`prd-pipeline:prd-core-pm`). Навык это учитывает сам.

## Правка словами

«Поменять словами» создаёт черновик - копию навыка и агентов в `dataDir/drafts/<id>/` - и запускает тред Claude Code по инструкции `dataDir/DRAFT.md` (плагин пишет её перед запуском). Тред правит только черновик и проверяет себя через RPC плагина:

```bash
bb plugin rpc call prd-pipeline draft_render --input-file <dataDir>/drafts/<id>/rpc.json
bb plugin rpc call prd-pipeline draft_check  --input-file <dataDir>/drafts/<id>/rpc.json
bb plugin rpc call prd-pipeline draft_diff   --input-file <dataDir>/drafts/<id>/rpc.json
```

«Принять» переносит только изменённые файлы; если рабочий навык за это время изменился в тех же файлах - отказ.

## Без bb

Логика - `core/core.mjs`, её можно запускать из командной строки. Папки - переменные окружения `PRD_SKILL_DIR`, `PRD_AGENTS_DIR`, `PRD_DATA_DIR` (пусто - как в таблице настроек).

```bash
node core/core.mjs check                 # ошибки меток навыка
node core/core.mjs check --draft <id>    # то же для черновика
node core/core.mjs render --draft <id>   # переписать метки черновика по его settings.json
node core/core.mjs diff --draft <id>     # что изменено в черновике
node core/test_core.mjs                  # 28 проверок на копии навыка из plugins/prd-pipeline во временной папке
```

## Метки в текстах навыка

| Метка | Что | Где правится |
|---|---|---|
| `<!--p:ключ-->600<!--/p-->` | число или строка из `params` | «Параметры» |
| `<!--c:ключ#слот-->текст<!--/c-->` | вариант текста выбора (режим, концепция) | «Параметры» |
| `<!--a:prd-агент-->Sonnet · medium<!--/a-->` | модель из шапки агента | «Агенты» |
| `<!--gen:flow.lite-->…<!--/gen-->` | шаги цепочки из `flows` | «Цепочка» |

Метки руками не правьте: число, которое должно меняться из панели, - новый параметр в `params` и метка в тексте.
